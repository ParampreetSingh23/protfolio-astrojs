## What is DRIP?

DRIP is an AI-powered developer productivity platform described in Parampreet Singh's work at Rabbitt AI. It supports code generation, debugging, refactoring, and contextual developer assistance across multiple LLM providers. Its supplied technology stack includes Next.js, React, TypeScript, Tailwind CSS, Node.js, AI and LLM APIs, PostgreSQL, Prisma, Docker, Git, and AWS. The project scope includes a scalable frontend, authentication, modular API architecture, server-side rendering, state management, GitHub Actions, and AWS deployment. These pieces connect the developer-facing interface to backend assistance and persistent application data. The portfolio architecture is an explanatory diagram of those components, not a product screenshot or an exact request trace. No usage, accuracy, latency, production scale, or business outcome is claimed here. The purpose of these field notes is to explain the system's documented responsibilities while leaving implementation artifacts and measured results open for future evidence.

## What does the platform cover?

- Contextual developer assistance for generating, debugging, and refactoring code.
- Multiple LLM provider integrations.
- Authentication and modular backend APIs.
- Server-side rendering and frontend state management.
- Containerization, CI/CD, and AWS deployment.
