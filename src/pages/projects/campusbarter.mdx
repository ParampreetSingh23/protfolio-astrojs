## What is CampusBarter?

CampusBarter is a peer-to-peer campus marketplace in Parampreet Singh's supplied project history. Its core stack is React, Node.js, Express, PostgreSQL, Drizzle ORM, and WebSockets. The platform combines Google OAuth and local authentication with real-time chat, allowing marketplace interactions to connect identity, persisted data, and conversations. The supplied feature list also includes serverless PostgreSQL, React Query, Zod, Tailwind CSS, and deployment on Render. React Query manages server-facing state, Drizzle supplies the database layer, and WebSockets support real-time communication. ## How do the responsibilities separate?

- **React:** marketplace interface and client interactions.
- **Express / Node.js:** backend APIs and authentication.
- **Google OAuth / local authentication:** account access.
- **WebSockets:** real-time chat.
- **PostgreSQL / Drizzle:** serverless database persistence.
- **React Query / Zod:** server state and validation.
- **Tailwind / Render:** styling and deployment.
